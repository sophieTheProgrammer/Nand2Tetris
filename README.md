## NAND2TETRIS
THIS IS MY IMPLEMENTATIONS OF THE NAND2TETRIS COURSE
Where you build a computer from first principles from the NAND gate and progress to a computer you can write programs and play snake in
I am doing it on the Nand2Tetris IDE, but I'm putting it on github for a record

Week 1 - Created elementary gates like AND, NOT, OR, XOR, MUX, DMUX and their 16 bit implementations from only Nand
Week 2 - Made an ALU, first made a HalfAdder that takes in 2 bits and then a FullAdder that takes in 3 bits
